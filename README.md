# Rust Cheat Sheet

Türkçe açıklamalar ve İngilizce kod örnekleriyle, A4 yatay baskıya uygun Rust çalışma notları. HTML dosyaları CSS ve çizimleri kendi içinde barındırır; kurulum gerektirmez.

## Dosyalar

| Dosya | Kapsam | Sayfa |
| --- | --- | --- |
| [rust-a4.html](rust-a4.html) | Temel konular ve ownership birlikte | 5 |
| [rust-ownership-a4.html](rust-ownership-a4.html) | Stack, heap, Copy, Box, move, drop ve String | 3 |

Kapsam, [Brown sürümü The Rust Book](https://rust-book.cs.brown.edu/) kitabının 1–3. bölümleri ve [4.1 içinde “Collections Use Boxes” başlığı](https://rust-book.cs.brown.edu/ch04-01-what-is-ownership.html#collections-use-boxes) dahil olacak şekilde hazırlanmıştır.

Ownership çizimleri, kodda işaretlenen L1–L4 anlarında değerleri ve sahipliği gösterir. Şemalar kavramsaldır; fiziksel bellek yerleşimi garantisi vermez. “Derlenmez” olarak işaretlenen örnek, move sonrası kullanımdaki derleyici hatasını göstermek için özellikle hatalıdır.

## Kullanım

1. Repoyu indirin veya klonlayın.
2. İstediğiniz HTML dosyasını tarayıcıda açın.
3. **Yazdır / PDF kaydet** düğmesini kullanın.

Baskı için A4, yatay yön ve %100 ölçek seçin. Tarayıcının üstbilgi ve altbilgilerini kapatın; renkli kutular için arka plan grafikleri seçeneğini açın. Sayfa ölçüleri 297 × 210 mm olarak sabittir. Dar ekranlarda yatay kaydırma kullanılabilir.

## Kaynaklar

İçerik, Brown sürümü The Rust Book ve [resmî Rust dokümantasyonuna](https://doc.rust-lang.org/) dayanır. İncelenen tasarımlar ve ilgili kaynak bağlantıları HTML dosyalarının sonundaki kaynaklar bölümünde bulunur.
