KİŞİSEL RUST NOTLARI / 03 · OWNERSHIP 1/3

Rust / Stack ve değerler

Çağrıdan önce, çağrı sırasında, dönüşte.
Brown · 4.1 · Collections Use Boxes dahil

Örnek / L1 → L2 → L3

fn increment(value: i32) -> i32 {
    let result = value + 1; // L2
    result
}
fn main() {
    let number = 5; // L1
    let next = increment(number); // L3
    println!("{number} {next}");
}

Bellek resmini nasıl okuyacağız?

Frame
Bir fonksiyon çağrısının yerel bağlamalarını gösteren kutu. Çağrı başlar, frame eklenir; çağrı biter, kaldırılır.
Stack
Etkin çağrıların frame’leri. Burada en yeni çağrıyı üstte çiziyoruz; ilk o döner.
Heap
Bir fonksiyon frame’ine bağlı olmadan yaşayabilen ayrılan alanlar. Sonraki sayfada Box ile göreceğiz.

L1–L3, kodda işaretlenen satır tamamlandıktan sonraki anı gösterir. number ve value ayrı bağlamalardır.

Bir fonksiyon çağrısının üç anı

Akış: soldan sağa →

Copy: bağımsız iki değer

let a = 5;
let mut b = a;
b += 3;
println!("{a} {b}"); // 5 8

i32 tipi Copy olduğu için b ayrı bir değer alır. b değişince a değişmez.

Önemli ayrım

Copy, bir tip özelliğidir; “stack’te olan her şey kopyalanır” kuralı yoktur. String ve Box<T> değerle aktarılırken taşınır.

Bu modeldeki kutular gerçek bellek adresleri değildir. Derleyici değerleri register’da tutabilir veya işlemleri optimize edebilir.

KİŞİSEL RUST NOTLARI / 04 · OWNERSHIP 2/3

Rust / Box, move ve drop

Tek ayrılan alanın sahibini takip et.
Brown · 4.1 · Collections Use Boxes dahil

Örnek / sahiplik a → b

fn main() {
    let a = Box::new([2, 4, 6]); // L1
    {
        let b = a; // L2
        println!("{}", b[0]);
    } // L3: b is dropped
}

Box değeri ile içindeki veriyi ayır

a, heap’teki [2, 4, 6] dizisini sahiplenen bir Box değeridir. Şemadaki ok, pointer’ın işaret ettiği veriyi gösterir.

let b = a; bir move işlemidir. b sahipliği alır; a eski değerini artık okuyamaz. Dizi heap’te ikinci kez oluşturulmaz.

canlı heap verisi / aktif sahipmoved / okunamazfonksiyon frame’i

H1 aynı ayrılan alanın kimliğidir; gerçek bir adres değildir. moved, “değer sıfırlandı” veya “null oldu” demek değildir.

Oluştur → taşı → bırak

Bu üç kare aynı programın farklı anlarıdır.

Derlenmez / E0382

let a = Box::new([2, 4, 6]);
let b = a;
println!("{}", a[0]); // ERROR: moved

H1 hâlâ b tarafından sahiplenilse de a üzerinden okuma reddedilir.

Bellek neden yalnızca bir kez bırakılır?

Normal kapsam çıkışında mevcut sahibin değeri bırakılır. Böylece aynı alanın iki kez serbest bırakılması ve bırakılmış veriye erişim engellenir.

drop(b) de Box’ın sahipliğini alıp erken bırakabilir. Move, kaynak yönetimini aktarır; heap verisini taşıması veya her zaman sıfır byte kopyalaması gerekmez.

KİŞİSEL RUST NOTLARI / 05 · OWNERSHIP 3/3

Rust / String’in yolculuğu

Çağrı, büyüme ve dönüşte aynı veriyi izle.
Brown · 4.1 · Collections Use Boxes dahil

Örnek / first → name → full

fn add_suffix(mut name: String) -> String {
    // L2: on entry, before push_str
    name.push_str(" Jr."); // L3
    name
}
fn main() {
    let first = String::from("Ada"); // L1
    let full = add_suffix(first); // L4
    println!("{full}");
}

String’in üç bilgisi

ptr
UTF-8 tamponunu gösteren pointer.
len
Kullanılan byte sayısı: “Ada” için 3, “Ada Jr.” için 7.
capacity
Tamponun byte kapasitesi; len değerinden küçük olamaz.

Şemalarda C ilk kapasite, C′ ekleme sonrası kapasitedir. Heap’te yalnızca kullanılan byte’lar çizilir. Alanların fiziksel sırası gösterilmez. L2 fonksiyona giriş anıdır.

“Collections Use Boxes”: String ve Vec heap alanını sahiplenir; doğrudan bir Box<T> alanı kullanmaları gerekmez.

Kapasite yeterliyse / C ≥ 7

Yeniden ayırma yapılmaz.
P′ = P, C′ = C.
Yalnızca kullanılan uzunluk 7 olur.

Kapasite yetmezse / C < 7

Tampon büyütülür; C′ ≥ 7.
Adres değişebilir, aynı da kalabilir. Belirli bir büyüme miktarı garanti edilmez.

Dönüş, veriyi bırakmaz

L4’te fonksiyon frame’i kalktı; döndürülen String’in sahibi full oldu. Sonrasında normal kapsam çıkışında full bu tamponu bırakır.

first, L2’den itibaren moved durumundadır; gri satır okunabilir bir eski pointer göstermez. full, ancak dönüş tamamlanınca başlatılır. Diyagramda boşluk ␠ ile gösterilir.
